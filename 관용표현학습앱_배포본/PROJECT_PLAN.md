# 「관용 표현을 찾아라!」 기획안

## 1. 한눈에 보는 프로젝트

| 항목 | 내용 |
| --- | --- |
| 프로그램 이름 | 관용 표현을 찾아라! |
| 대상 | 초등학교 6학년 학생 |
| 교과 | 국어 |
| 학습 주제 | 문맥에 알맞은 관용 표현의 뜻과 쓰임 이해하기 |
| 활동 시간 | 약 10~15분 |
| 개인정보 | 이름 없이 학생 번호만 사용 |

## 2. 기획 의도

관용 표현은 말의 겉뜻만 보고 이해하기 어려워, 문장 속 상황을 함께 살펴보는 연습이 필요합니다. 이 활동은 학생이 짧은 상황을 읽고 가장 알맞은 뜻이나 관용 표현을 고르도록 구성했습니다.

단순히 최종 정답만 확인하지 않고 **처음 고른 답**을 따로 기록합니다. 학생이 처음부터 이해했는지, 다시 생각한 뒤 정답을 찾았는지를 구분하기 위해서입니다. 틀린 답을 골라도 정답을 찾을 때까지 다시 시도할 수 있게 하여, 평가보다 학습 경험에 초점을 두었습니다.

교사는 활동이 끝난 뒤 학생 번호별 결과와 학급 전체 결과를 함께 볼 수 있습니다. 이를 통해 어느 문항에서 어려움을 겪었는지, 어떤 선택지를 많이 골랐는지, 답을 고르는 데 시간이 오래 걸린 문항은 무엇인지 쉽게 파악할 수 있습니다.

## 3. 화면 구성과 사용 흐름

### 학생용 화면

1. 학생은 이름 없이 학생 번호만 입력합니다.
2. 같은 번호의 기록이 이미 있으면, 다시 활동할지 먼저 확인합니다.
3. 한 화면에 한 문항씩 총 5문항이 나옵니다.
4. 선택지는 활동을 시작할 때마다 순서가 섞여 나옵니다.
5. 처음 선택한 답과 그때까지 걸린 시간이 기록됩니다.
6. 첫 답이 틀려도 정답을 찾을 때까지 다시 고를 수 있습니다.
7. 정답을 골라야 다음 문항으로 갈 수 있습니다.
8. 활동이 끝나면 점수, 첫 응답 정답률, 평균 응답 시간, 문항별 결과와 해설을 확인합니다.

### 교사용 화면

교사용 분석 버튼을 누르면 같은 브라우저에 저장된 결과를 분석할 수 있습니다.

- 참여 학생 수
- 학급 평균 점수
- 전체 첫 응답 정답률
- 전체 평균 응답 시간
- 문항별 정답률, 평균 시간, 중앙값 시간
- 선택지별 응답 인원과 비율
- 정답률이 가장 낮은 문항
- 평균 응답 시간이 가장 긴 문항
- 학생 번호별 개인 결과
- CSV 저장, 표 복사, 인쇄

## 4. 제작 방법

### 디자인

학생이 오래 보아도 부담스럽지 않도록 밝은 하늘색과 따뜻한 크림색을 기본 배경으로 사용했습니다. 제목과 핵심 수치는 진한 파란색으로 표시해 눈에 잘 들어오게 했습니다.

선택 버튼의 높이는 충분히 크게 만들고, 버튼 사이 간격을 넓혔습니다. 태블릿과 휴대전화에서도 누르기 쉽도록 조정했습니다. 정답과 오답은 초록색·빨간색 계열로 구분하지만, 색만으로 판단하지 않도록 안내 문장도 함께 제공합니다.

교사용 화면은 많은 정보를 한 번에 읽어야 하므로 요약 카드와 표를 중심으로 구성했습니다. 특히 정답률이 낮은 문항과 시간이 오래 걸린 문항은 색이 다른 카드로 먼저 보여 줍니다.

### 스크립트 구조

프로그램은 이해와 유지 관리를 쉽게 하기 위해 기능별로 나누었습니다.

| 파일 | 역할 |
| --- | --- |
| `index.html` | 학생과 교사가 보는 화면의 뼈대 |
| `css/style.css` | 색, 글자 크기, 버튼, 표, 인쇄 화면 디자인 |
| `js/questions.js` | 관용 표현 문항, 정답, 해설, 선택지 |
| `js/app.js` | 학습 시작, 답 선택, 재도전, 결과 화면 제어 |
| `js/analysis.js` | 저장, 점수 계산, 학급 통계, CSV 처리 |

문항 내용과 화면 동작을 분리해 두었기 때문에, 다음 활동을 만들 때는 주로 `questions.js`의 문항을 바꾸거나 추가하면 됩니다.

### 데이터 저장 방식

현재 버전은 별도 서버 없이 실행되며, 결과는 해당 기기의 브라우저 저장 공간에만 보관됩니다. 따라서 같은 기기와 같은 브라우저에서 학생 활동과 교사 분석을 진행할 때 적합합니다.

이 방식은 설치와 로그인 없이 간단히 사용할 수 있다는 장점이 있습니다. 반면 다른 기기에서 자동으로 결과가 모이지는 않습니다. 여러 기기의 결과를 모아야 할 때는 다음 단계에서 Firebase와 같은 온라인 저장소를 연결할 수 있도록 문항·분석·화면 기능을 분리해 두었습니다.

## 5. 학생 수준과 내용 적합성 검토 결과

### 적합한 점

- 6학년이 일상에서 만날 수 있는 발표, 친구 관계, 체육대회 상황을 사용했습니다.
- 문항마다 짧은 상황을 먼저 제시해 관용 표현의 쓰임을 문맥 속에서 이해하도록 했습니다.
- 4지선다 형식으로 읽기 부담을 줄였습니다.
- 첫 오답 뒤 다시 생각할 기회를 주어, 실수로 인한 좌절을 줄였습니다.
- 해설에서 관용 표현의 뜻을 짧고 분명하게 설명합니다.

### 수정하여 반영한 점

처음 검토에서 두 문항의 상황이 관용 표현의 실제 쓰임과 충분히 맞지 않는 점을 확인했습니다.

- `가슴을 쓸어내리다`: 발표 전 긴장이 아니라 발표가 무사히 끝난 뒤 안심하는 상황으로 고쳤습니다.
- `발이 넓다`: 준비물을 챙겨 주는 상황이 아니라 여러 학년에 아는 친구가 많은 상황으로 고쳤습니다.

이 수정으로 문항의 상황과 정답 의미가 더 자연스럽게 연결됩니다.

## 6. 기능 검토 결과

서로 다른 답 선택 패턴으로 10회 반복 검증을 진행했습니다.

- 모든 문항을 처음부터 맞힌 경우: 100점 정상 계산
- 모든 문항을 처음 틀린 뒤 맞힌 경우: 0점 정상 계산, 재도전 기록 확인
- 정답과 오답이 섞인 경우: 첫 응답 기준 점수 정상 계산
- 빈 번호와 문자 포함 번호: 시작 차단 확인
- 같은 번호의 기존 기록: 시작 전 확인 창과 최신 결과 교체 확인
- 선택지 무작위 배치: 정답 누락·선택지 중복 없음 확인
- 교사용 참여 인원, 문항 분석, 개인 분석: 정상 표시 확인

상세 결과는 `TEST_REPORT.md`에서 확인할 수 있습니다.

## 7. 운영 시 유의점

- 활동 전 학생에게 이름을 입력하지 않도록 안내합니다.
- 교사용 분석은 학생 활동에 사용한 같은 기기와 브라우저에서 확인합니다.
- 브라우저의 저장 데이터를 지우면 결과도 함께 사라집니다.
- 실제 수업 전에는 시험용 학생 번호로 한 번 활동을 끝까지 진행해 보는 것을 권장합니다.
- CSV 저장과 인쇄 기능은 사용하는 브라우저에서 사전에 한 번 확인합니다.

## 8. 다음 확장 방향

현재 구조는 다양한 관용 표현을 넣는 활동으로 확장하기 쉽습니다. 다음 단계에서는 관용 표현 문항을 충분히 추가한 뒤, 활동을 시작할 때 그중 일부를 무작위로 골라 제시하는 방식으로 발전시킬 수 있습니다. 이때도 첫 응답 기록, 개인 분석, 교사용 분석 기능은 그대로 활용할 수 있습니다.
