# 관용 표현을 찾아라!

초등학교 6학년 국어 수업용 관용 표현 학습 앱입니다. 이름을 수집하지 않고 학생 번호만 사용합니다.

상급자용 기획·검토 문서는 [PROJECT_PLAN.md](PROJECT_PLAN.md)에서 확인할 수 있습니다.

## 실행 방법

`index.html` 파일을 웹 브라우저로 열면 실행됩니다. 별도 서버나 외부 서비스가 필요하지 않습니다.

## 기능

- 5개 관용 표현 문항과 선택지 무작위 배치
- 문항별 첫 선택, 첫 응답 정오, 첫 응답 시간 기록
- 오답 후 재도전 및 정답 후 다음 문항 이동
- 100점 만점 개인 결과와 문항 다시 보기
- 같은 브라우저의 localStorage에 학생별 결과 저장
- 같은 번호로 재활동할 때 최신 결과로 교체 여부 확인
- 교사용 전체·개인 분석, 문항별 선택지 분포, 평균·중앙값 시간
- 개인·전체 CSV 다운로드, 복사, 인쇄

## 데이터와 개인정보

- 저장하는 정보는 학생 번호와 학습 응답뿐입니다.
- 이름, 연락처 등 개인정보를 저장하지 않습니다.
- 데이터는 현재 브라우저의 localStorage에만 저장되므로 다른 기기와 자동 공유되지 않습니다.
- 실제 수업 전에는 브라우저 저장 데이터를 지우지 않도록 안내해 주세요.

## Firebase 확장

현재 버전은 외부 서버 없이 동작합니다. `js/questions.js`, `js/analysis.js`, `js/app.js`가 분리되어 있어 이후 Firestore 저장소로 바꾸기 쉽습니다. Firebase 프로젝트 생성, 연결, 인증 설정, 실제 배포는 이 버전에서 수행하지 않았습니다.

## 수동 테스트 체크리스트

1. 빈 학생 번호와 문자 번호로 시작이 차단되는지 확인합니다.
2. 문항마다 선택지 순서가 달라지는지 확인합니다.
3. 첫 오답 뒤 정답을 골라도 첫 응답 결과가 오답인지 확인합니다.
4. 정답 전에는 다음 문항 버튼이 나타나지 않는지 확인합니다.
5. 5문항 완료 후 점수가 첫 응답 기준으로 계산되는지 확인합니다.
6. 같은 번호의 결과를 다시 저장할 때 교체 확인이 나타나는지 확인합니다.
7. 교사용 분석에서 참여 수, 정답률, 분포, 시간 통계가 맞는지 확인합니다.
8. CSV 다운로드·복사·인쇄 버튼을 확인합니다.
