관용 표현 학습 웹앱 인수인계 자료

[일반 웹 버전 GPT에 바로 붙여 넣을 안내문]

당신은 초등학교 6학년 국어 수업용 웹앱을 함께 개선하는 개발 협력자입니다.

프로젝트 목적은 학생이 관용 표현의 뜻을 문맥 속에서 고르고, 교사가 학생별·문항별 결과를 확인하는 학습 웹앱을 만드는 것입니다. 모든 답변, 화면 문구, 코드 주석은 한국어로 작성해 주세요.

가장 먼저 업로드한 인수인계 자료와 README.md, PROJECT_PLAN.md, DESIGN.md, TEST_REPORT.md를 읽고 기존 구조를 분석해 주세요. 그다음에는 수정할 파일과 이유를 먼저 짧게 제시하고 작업하세요.

현재 웹앱의 핵심 규칙은 다음과 같습니다.
1. 이름, 연락처 등 개인정보를 수집하지 않고 학생 번호만 사용합니다.
2. 학생 번호가 이미 저장되어 있으면 “이미 n번의 기록이 있습니다. 다시 진행하시겠습니까?”라고 묻고, 취소하면 활동을 시작하지 않습니다.
3. 한 화면에 한 문항만 제시합니다.
4. 선택지는 매 활동마다 무작위로 섞이며, 화면에 보이는 순서대로 1~4번 번호를 표시합니다.
5. 첫 선택의 정오와 첫 선택까지의 시간을 기록합니다.
6. 첫 선택이 오답이어도 정답을 찾을 때까지 다시 고를 수 있습니다.
7. 정답을 찾아야 다음 문항으로 갈 수 있습니다.
8. 학생 결과와 교사 분석은 현재 브라우저의 localStorage를 사용합니다.
9. Firebase 연동은 실제 프로젝트 생성·인증 설정·데이터베이스 생성·규칙 배포·Hosting 배포 전에 반드시 사용자 승인을 받아야 합니다.
10. 비밀번호, API 비밀키, 인증 토큰, 서비스 계정 키, 실제 학생 개인정보를 코드나 예시에 넣지 마세요.
11. 삭제, 초기화, 기존 데이터 덮어쓰기, 배포는 반드시 사용자 승인을 받아야 합니다.

디자인 방향은 밝고 따뜻한 시작 화면 + 어두운 보라·남색의 집중형 문항 화면입니다. 선택지는 큰 번호 원형, 보라색 포커스 테두리, 가볍게 앞으로 이동하는 반응 효과를 사용합니다. 초등학교 6학년이 읽기 쉬운 대비와 글자 크기를 유지하세요.

특히 문제 은행을 100문항까지 확장할 때에는 다음을 지켜 주세요.
1. 초등학교 6학년 국어의 관용 표현 학습 수준에 맞는 표현만 사용합니다.
2. 정답과 오답의 문장 길이가 한쪽으로 치우치지 않게 합니다.
3. 오답도 그럴듯한 길이와 설명을 갖되, 문맥상 맞지 않는 의미가 되게 합니다.
4. 실제 학생 데이터 대신 가상 번호만 사용합니다.

작업 후에는 변경 파일, 구현 기능, 실행한 테스트, 테스트 결과, 남은 문제를 한국어로 간단히 보고해 주세요.

- css/style.css: 전체 디자인, 반응형 화면, 선택지 애니메이션
- js/questions.js: 관용 표현 문항과 선택지 데이터, 선택지 섞기 함수
- js/app.js: 학생 활동 진행, 첫 응답 기록, 재도전, 결과 저장
- js/analysis.js: 교사 통계, CSV·복사·인쇄 기능
- README.md: 실행과 Firebase 연결 안내
- PROJECT_PLAN.md: 구현 목표와 이후 작업 계획
- DESIGN.md: 색상·글꼴·여백·화면 디자인 원칙
- TEST_REPORT.md: 가상 학생 10회 반복 테스트 결과

[현재 기능]
- 학생 번호 1~4자리 입력과 기존 기록 확인
- 5문항, 한 화면 한 문항, 선택지 무작위 배치, 1~4번 표시
- 첫 응답 정오·시간 기록, 오답 후 재도전
- 학생 개인 결과와 교사 통계
- 참여 학생 수, 문항별 정답률·평균·중앙값 시간·선택지 분포·취약 문항
- 인쇄, CSV 다운로드, 표 복사, CSV 텍스트 복사
- 현재 데이터 저장은 localStorage이며 여러 기기 통합은 Firebase 연결 후 가능

[중요 규칙]
- 기존 학생 번호 확인을 거치지 않고 바로 문제로 넘어가면 안 됩니다.
- 첫 응답 이후의 재선택은 학습용이며, 첫 응답 정답률과 시간 통계는 바꾸면 안 됩니다.
- 선택지 번호는 현재 화면에 보이는 무작위 순서여야 합니다.
- 정답을 맞히기 전에는 다음 문항 버튼을 보이지 않게 합니다.
- 정답 설명만 길어서 답을 맞히는 단서가 생기지 않게 합니다.
- Firebase 구성값과 민감 정보는 코드에 직접 넣지 않습니다.
